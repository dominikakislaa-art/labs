# Карта этажей учебного корпуса

Схема помещений корпуса «Б». Нумерация: первая цифра — этаж, далее порядковый номер.

## 1 этаж

| №   | Помещение       | Вместимость |
|-----|-----------------|-------------|
| 101 | Вестибюль       | —           |
| 102 | Гардероб        | —           |
| 103 | Деканат         | —           |
| 104 | Аудитория 104   | 30          |
| 105 | Аудитория 105   | 24          |

```
1 этаж:  [101]—[102]—[103]—коридор—[104]—[105]
```

## 2 этаж

| №   | Помещение       | Вместимость |
|-----|-----------------|-------------|
| 201 | Аудитория 201   | 40          |
| 202 | Аудитория 202   | 32          |
| 203 | Кафедра ИТ      | —           |
| 204 | Аудитория 204   | 28          |
| 205 | Аудитория 205   | 20          |

```
2 этаж:  [201]—[202]—[203]—коридор—[204]—[205]
```

## Легенда

- **Аудитория** — учебное помещение с проектором.
- **Кафедра** — административное помещение.
- **Лаборатория** — помещение для практических занятий с оборудованием.

## Правила обновления схемы

1. Номер помещения меняется только вместе с записью в приказе по корпусу.
2. Новые помещения добавляются в таблицу своего этажа и в ASCII-схему.
3. После изменений проверяется, что номера в таблице и на схеме совпадают.
