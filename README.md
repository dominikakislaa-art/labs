## Постановка задачи

### 14. Карта этажей учебного корпуса (текстовая схема)

ASCII/Markdown-схема помещений. Ветка `renumber-rooms` меняет нумерацию; ветка `add-labs` добавляет лаборатории, затрагивая те же фрагменты схемы. Разрешите конфликт схемы.

### Общие правила

- Язык мини-проекта на выбор; достаточно небольшого объёма, чтобы конфликт был наглядным.
- Конфликт должен быть реальным: две ветки меняют одни и те же строки по-разному.
- В истории коммитов видно: начальная работа → работа в ветках → конфликт → разрешение → синхронизация с remote.
- Сообщения коммитов осмысленные, единый стиль.
- Не удалять историю после разрешения конфликта.
- Репозиторий публичный (или доступный по ссылке без запроса доступа).
