## Постановка задачи

### 14. Корзина интернет-магазина

Позиция: название, цена, количество. Операции: добавить/изменить количество, удалить позицию, итоговая сумма, количество уникальных позиций.

### Общие требования к реализации

Цель: на одной предметной задаче сравнить структурный и объектно-ориентированный стили реализации.

Каждый студент получает **одну** задачу (номер задачи соответствует номеру в журнале). Нужно выполнить её **дважды**:

1. **Структурный стиль** — функции/процедуры + данные (структуры, словари, массивы). Логика живёт в функциях; данные и поведение разделены.
2. **ООП-стиль** — классы с инкапсуляцией состояния и методов. Ответственность распределена по объектам предметной области.

Общие правила:

- Язык на выбор: Python, Java, C#, JavaScript/TypeScript, ... (один язык для обоих вариантов).
- Оба решения решают **одну и ту же** постановку задачи и дают одинаковый по смыслу результат.
- Ввод/вывод — консольный или через простой интерактив в начале программы.
- Без внешних библиотек (кроме стандартной библиотеки языка).
- Код должен быть читаемым: понятные имена, краткие комментарии там, где без них неочевидно «почему».
- В каждом варианте — небольшой демонстрационный сценарий (несколько примеров входных данных).

## Реализованные операции

| Операция | Структурный стиль | ООП-стиль |
|----------|-------------------|-----------|
| Добавить позицию / увеличить количество | `add(cart, name, price, qty=1)` | `Cart.add(name, price, qty=1)` |
| Изменить количество | `set_qty(cart, name, qty)` | `Cart.set_qty(name, qty)` |
| Удалить позицию | `remove(cart, name)` | `Cart.remove(name)` |
| Итоговая сумма | `total(cart)` | `Cart.total` |
| Количество уникальных позиций | `count(cart)` | `len(cart)` |
| Найти позицию | `find(cart, name)` | `Cart.find(name)` |
| Печать корзины | `report(cart)` | `Cart.report()` |

### Правила

- Названия сравниваются без учёта регистра и лишних пробелов: `"  молоко "` и `"Молоко"` — одна позиция.
- Повторное добавление существующей позиции увеличивает количество и обновляет цену на новую.
- Цена и количество должны быть больше нуля, иначе `ValueError`.
- Удаление отсутствующей позиции — `ValueError`.
- Итог считается как сумма `цена × количество` по всем позициям.

## Демонстрационный сценарий

1. Добавляются Молоко (2.50 × 2), Хлеб (1.20 × 1), Сыр (5.40 × 1) — итого 11.60.
2. Повторно добавляется молоко по 2.80 — количество становится 3, цена обновляется.
3. Количество Хлеба меняется на 4.
4. Сыр удаляется.
5. Проверяются ошибки: удаление несуществующего Кефира, количество 0, пустое название.
6. Печатается итог: 2 позиции, сумма 13.20.


## Чем отличаются реализации

**`structural.py`** — корзина это обычный словарь, позиция — словарь с полями `name`, `price`, `qty`. Все правила вынесены в функции, которые получают корзину первым аргументом. Данные и поведение разделены: словарь можно изменить в обход функций.

**`oop.py`** — `Item` хранит название, цену и количество в закрытых полях и умеет считать свою сумму; `Cart` владеет набором позиций и реализует операции. Состояние меняется только через методы, поэтому правила (положительная цена, поиск без учёта регистра) не обойти.

Результат работы обеих версий одинаковый.
